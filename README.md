# Program Neural Networks with TensorFlow

This repository contains code examples and exercises completed as part of the **Program neural networks with TensorFlow** learning pathway by Google for Developers. 

The pathway covers foundational machine learning concepts, transitioning from basic programming paradigms to building Convolutional Neural Networks (CNNs) for image recognition and classification.

## Repository Contents

* **01 - The Hello World of Machine Learning**: Basic intro to machine learning principles and model building with TensorFlow.
* **02 - Introduction to Computer Vision**: Writing code to recognize fashion items using computer vision techniques.
* **03 - Introduction to Convolutions**: Exploring how convolutions and pooling work to extract features from images.
* **04 - Convolutional Neural Networks (CNNs)**: Implementing CNNs to improve image classification accuracy.
* **05 - Complex Images**: Training models on more intricate datasets and handling real-world image structures.
* **06 - Use CNNs with Larger Datasets**: Scaling CNN models to process larger and multi-class image datasets.

## Prerequisites

* Python 3.x
* TensorFlow 2.x
* Jupyter Notebook / Google Colab
